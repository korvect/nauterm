# Noto fonts bundled by Nauterm RS for Windows and Linux

- `NotoSans-*.ttf`: [Noto Sans v2.015](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015), proportional static TrueType faces.
- `NotoSansCJK-*.ttc`: [Noto Sans CJK 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTC), OpenType collections containing the proportional SC, TC, JP, KR, and HK families. The bundled Regular and Bold collections are derived from upstream by removing their Noto Sans Mono CJK faces; Medium already contains only proportional faces.

See the [Noto Sans](../../licenses/manual/noto-sans-OFL.txt) and
[Noto CJK](../../licenses/manual/noto-cjk-OFL.txt) license notices.

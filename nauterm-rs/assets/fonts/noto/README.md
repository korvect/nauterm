# Noto fonts bundled by Nauterm RS for Windows and Linux

- `NotoSans-*.ttf`: [Noto Sans v2.015](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSans-v2.015), normal-width static TrueType faces.
- `NotoSansMono-*.ttf`: [Noto Sans Mono v2.014](https://github.com/notofonts/latin-greek-cyrillic/releases/tag/NotoSansMono-v2.014), static TrueType faces.
- `NotoSansCJK-*.ttc`: [Noto Sans CJK 2.004](https://github.com/notofonts/noto-cjk/tree/Sans2.004/Sans/OTC), official OpenType collections. Regular and Bold contain both proportional and monospace families. The client uses the SC, TC, JP, and KR families.

The OpenType collections share font data between regional and monospace faces.
See the [Noto Sans](../../licenses/manual/noto-sans-OFL.txt) and
[Noto CJK](../../licenses/manual/noto-cjk-OFL.txt) license notices.
